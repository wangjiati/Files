## 1. KPI 与 Explorer 参照基准

测量方法沿用上游 #19028 的成熟方法论（`SetWindowPos` 同步跨进程计时，可同时对 Files 与 explorer.exe 任一 HWND 使用）。当前参照值来源：上游 #19028（2026-10 实测）、本仓库调查报告 §1/§2。

| # | KPI | Files 现状 | Explorer 参照 | 目标 |
| --- | --- | --- | --- | --- |
| K1 | 窗口拖动：每次移动 UI 线程耗时中位 | 33-41 ms（4.3.0，#19028） | 3-4 ms | ≤10 ms（WinUI 架构差异下"接近"）；批次 2 实测 dev A/B 10.21→6.73 ms（-34%，vs 同日 Explorer 0.97），dev 口径达标（Release 因打包阻断未复核） |
| K2 | 窗口 resize：每次耗时 p95 / max | 96 / 688 ms（#19028） | 62-75 / 100 ms | ≤ Explorer；批次 2 实测 p95 18.37→14.29 ms（-22%，优于 Explorer §2 参照 32-33）但 p50 12.03 仍高于 Explorer ~3.4，部分达标 |
| K3 | 目录导航：UI 线程同步磁盘 I/O | 每次导航全链（FRN+DB+ADS+ini+枚举） | 无 | 预测命中路径 0（批次 1 C5）；FRN/DB/ADS 残留顺延批次 3 |
| K4 | 冷启动到可交互 | 待测 | 待测 | 建立基线后定 |
| K5 | 空闲内存（加载一目录后 60s） | 基线 386.8 MB（便携 Release，§1） | n/a | 长会话不增长；批次 3 实测 dev A/B（30 目录导航后 60 s 空闲，单轮）：A 486.8 → B 441.3 MB 中位（**-9.3%**），斜率 A -1.2、B -4.1 MB/min；批次 4a 三轮均值（30 目录导航+50k 大目录翻滚尾段，每轮独立会话）：B 导航末 443.8±1.9、空闲中位 558.0±0.4、首末斜率 **+0.1 MB/min**（-1.6..+2.7）——平坦无增长达标；A 单轮同口径 442.6/552.1/-0.7（批次 3 的 -9.3% 未复现，A 亦降至 ~443，B 跨批次稳定）——B 不劣于 A 维持，严格斜率优势两侧均在噪声内未证 |
| K6 | 图片预览解码内存（≥4000×3000，RightTabs 切 10 次） | 数百 MB 级波动 | n/a | 峰值 ≤17MB/张（批次 1 M2） |
| K7 | 大目录（50k 项）加载 | 待测 | 待测 | 建立基线后定；未覆盖，顺延批次 4（C3/C4 主战场） |

规则：每项修复必须对应至少一个 KPI 的前后同配置测量；无法测量的修复不进批次。

## 3. 工程闭环（已在 2026-11-11 会话中实战验证）

调查（并行分域）→ **三路佐证**（M1 被证伪证明此关必需）→ 专家评估（设计裁决）→ 批次计划（writing-plans，钉死取值与验证）→ SDD 执行（实现/审查循环，5 轮熔断）→ 同口径测量（便携 Release 前后构建）→ 打包冒烟 → 批次收尾（裁决公示、KPI 更新、上游观察）。

## 5. 裁决记录（含代价）

- R1（2026-11-11）：M1 SpeedGraph 从所有批次撤销——三路佐证证伪；若错（运行时存在未知重入路径），代价 = 放弃一个可能的防御性加固，不影响其他项。
- R2：C5 用缓存+预取设计而非 20 调用点异步化——专家裁决；若错（预取覆盖不足导致布局预测命中率低），代价 = 部分文件夹首次进入多一次布局切换（有界回退）。
