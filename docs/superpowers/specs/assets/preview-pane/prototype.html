1预览区右上角 = 位置按钮（新增）
三个小图标按钮，副交互，不挤占工具栏；当前模式高亮。所在模式立即生效并记住。
2上下两行
上预览、下详情，中间可拖动分隔条。打开预览窗后两块同时可见，不再二选一。
3标签页
详情 / 预览 二选一。详情页维持现状：上面基础预览（图标/缩略图拉伸）、下面详情；预览页才是真预览、占满整块。
4底部通栏
预览与详情左右并排铺满列表下方。上沿分隔条拖高度（140–500 px），中间竖分隔条拖详情列宽（最窄 132 px，压窄后标签换行堆叠）。
5关闭态仍是默认
